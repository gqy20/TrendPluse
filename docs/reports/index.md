### [2026-05-10](report-2026-05-10.md){ .tp-date-badge }

> 2026年5月10日，AI Agent生态从"企业级集成"主叙事切换至"长尾应用发现与垂直分化"新阶段。今日143个候选项目（全部通过质量筛选，61.5%高优先级），历史首次全量高质量通过，标志着生态进入应用大爆发节点。被发现的项目群呈现清晰的垂直分化特征：Hermes Agent（142k⭐）、LlamaFactory（71k⭐）、RAGFlow（80k⭐）、OpenBB（67k⭐）、LocalAI（46k⭐）、lobehub（77k⭐）、claude-mem（74k⭐）分别代表金融交易、模型微调、RAG检索、边缘部署、多Agent协作、跨会话记忆等垂直赛道，而caveman（57k⭐，Token削减65%）和everything-claude-code（178k⭐）则代表生态工具层的MCP兼容Skill市场爆发。相比May 9日以MCP企业采纳（SAP）和多Agent编排框架为核心的企业层叙事，今日重心转移至应用层——这是该生态自2026年1月以来的"基础设施→企业集成→垂直应用"演进链条的最新节点。
