### 全局亮点

- **thinking_blocks 跨仓阻断**：56 个仓库在 Provider 切换（Claude→非 Claude）时因历史消息携带 thinking_blocks 语法导致 BadRequestError，形成「无恢复路径的完全阻断」
- **MCP 生态异步异常失控**：agno、crewAI、semantic-kernel 等 5 个仓库在 MCP Server 连接失败时抛出未捕获的级联 async generator 异常而非优雅降级
- **AGENTS.md 重复注入**：gptme/opencode/goose/cline 等 17 仓库因 ContextVar 未跨请求传播导致每次 cd 后重新加载配置文件，token 浪费且去重机制失效
- **并发内存约束缺陷**：agentscope 的 AsyncSQLAlchemyMemory 在 parallel_tool_calls 场景下触发外键约束失败和主键冲突（3 个相关 issue），暴露 ORM flush 时序问题
