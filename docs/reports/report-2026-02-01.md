## ⚠️ Breaking Changes

### [anthropics/claude-code-action](https://github.com/anthropics/claude-code-action) `v1`

- 🔴 **[Config]** 移除多个已弃用的输入参数（mode, direct_prompt, override_prompt, custom_instructions, model, allowed_tools, mcp_config, disallowed_tools, anthropic_model, trigger_phrase, timeout_minutes），统一替换为 prompt 和 claude_args
- 🟡 **[Behavior]** 自动模式检测取代手动 mode 配置，不再需要手动配置交互或自动化模式

### [danielmiessler/fabric](https://github.com/danielmiessler/fabric) `v1.4.397`

- 🟡 **[Dependency]** 2026年2月之前的旧版模型将被弃用，建议迁移至新的 Claude Sonnet 4.0 或 Opus 4.0 模型别名

### [openai/codex](https://github.com/openai/codex) `rust-v0.93.0`

- 🟡 **[Behavior]** 智能审批默认开启，MCP 工具调用现在需要显式审批
- 🟢 **[API]** 移除 WebSocket 线路格式，WebSocket 代理失败时会自动回退到 HTTP
- 🟢 **[Config]** 弃用旧的 Web 搜索功能标志，相关配置行为发生变更
- 🟢 **[Dependency]** Rust 工具链升级至 1.93 版本

### [anomalyco/opencode](https://github.com/anomalyco/opencode) `v1.1.48`

- 🟡 **[Behavior]** grep 和 ripgrep 操作默认不再跟随符号链接
- 🟡 **[API]** 使用 OpenAI 兼容 API 时，thinking 参数必须使用 snake_case 格式
- 🟢 **[Behavior]** 移除了 Google Vertex Anthropic 提供商在响应生成中的特殊处理逻辑
- 🟢 **[Config]** 聊天模型现在被排除在 textVerbosity 设置之外
