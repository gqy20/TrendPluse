- 新增 locator.drop() 方法，模拟外部文件或剪贴板数据拖放到元素上，支持 files 和 data 参数
- expect(page).toMatchAriaSnapshot() 现在支持直接对 Page 对象进行断言，等同于 page.locator('body')
- locator.ariaSnapshot() 和 page.ariaSnapshot() 新增 boxes 选项，追加元素边界框信息 [box=x,y,width,height]
- 新增 test.abort() 方法（内容被截断，推测为测试中止功能）

Playwright v1.60.0 带来多个重磅新特性：HAR 录制功能正式集成到 Tracing API 中，提供了一等公民的支持；新增 locator.drop() 方法用于模拟外部拖放操作，特别适合测试文件上传场景；Aria snapshot 功能得到增强，支持直接对 Page 断言并新增边界框信息。这是一个功能性版本，主要面向测试效率和跨浏览器兼容性的提升。
