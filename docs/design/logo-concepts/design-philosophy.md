# 明确信号

形体应呈现从观察到判断的过程。方向由少数明确的折转建立，信息通过实体与空隙的关系被辨认。每个转折都必须在缩小后仍然成立，不能依靠解释才能看清轮廓。

先以黑白验证结构。实体承担识别，空白承担分离；任何依赖渐变、透明叠加或装饰纹理才能成立的构图都不进入下一轮。小尺寸的像素对齐与大尺寸的光学平衡同样重要，需要逐一校准。

笔画粗细与间隙是整套标志的节奏。节点可以提示被识别出的变化，但必须成为结构的一部分。通过反复检查端点、内孔和转角，避免偶然的尖角、黏连或过细的连接。

字标提供稳定的阅读基础，符号提供辨识度。两者应保持光学上的均衡，紧凑但不挤压。最终打磨重点是细微的间距与重心调整，让细节经得起导航栏、浏览器标签及反白环境的检验。

本轮概念线索为：趋势拐点、多源信号汇聚、TP 字母结构。三个方向采用相同的黑白条件、原尺寸图标与导航示意比较，不在本轮直接替换网站资产。
