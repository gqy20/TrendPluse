## 欢迎使用 TrendPulse

TrendPulse 是一个智能的 GitHub 趋势分析工具，专注于追踪 **AI 编程工具和智能体**的最新动态。

### 核心功能

- 🔍 **智能筛选**: 从海量 GitHub 活动中筛选重要趋势
- 🤖 **AI 分析**: 使用 glm-4.7 提取关键信号和洞察
- 📊 **每日报告**: 自动生成结构化的趋势分析报告
- 🧠 **Issue 洞察**: 基于 Agent 提取用户痛点并输出质量分
- 🧭 **项目发现**: 自动发现并评估热门候选项目
- 📆 **周报聚合**: 聚合近 7 天日报生成 weekly 报告
- 🎯 **多维度**: 工程实践、研究成果、生态动向
