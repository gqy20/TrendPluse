#### 📦 [anthropics/claude-code-action](https://github.com/anthropics/claude-code-action) v1.0.77

**发布者**: `github-actions[bot]` | **时间**: 2026-03-23

**变更类型**: ✨ improvement

**变更摘要**:

- 为配置 allowed_non_write_users 的工作流自动启用子进程环境清理（CLAUDE_CODE_SUBPROCESS_ENV_SCRUB=1）
- 子进程环境不再包含 Anthropic 认证令牌、云提供商凭证、GitHub Actions OIDC 和运行时令牌、OTEL 认证头
- 保留 GITHUB_TOKEN/GH_TOKEN 以支持包装脚本调用 GitHub API
- 支持通过设置 CLAUDE_CODE_SUBPROCESS_ENV_SCRUB: "0" 在 job 或 step 级别选择退出
- 需要 Claude Code v2.1.79+ 版本配合使用

此版本为处理不受信任输入的工作流添加了子进程环境清理安全机制。当配置了 allowed_non_write_users 时，会自动设置 CLAUDE_CODE_SUBPROCESS_ENV_SCRUB=1，使 Claude Code 从子进程环境中剥离敏感凭证，防止通过提示注入攻击窃取 API 密钥等敏感信息。大多数用户无需操作即可获得增强的安全保护，如遇问题可通过设置 opt-out 或显式重新注入凭证解决。

**链接**: [查看详情](https://github.com/anthropics/claude-code-action/releases/tag/v1.0.77)
