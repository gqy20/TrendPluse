### [anthropics/claude-code-action](https://github.com/anthropics/claude-code-action) `v1`

- 🔴 **[API]** 输入参数 API 重构：移除 `mode`, `direct_prompt`, `override_prompt`，统一为 `prompt` 输入
- 🔴 **[Config]** 配置参数迁移：`custom_instructions`, `model`, `allowed_tools`, `mcp_config` 移至 `claude_args` 并采用 CLI 格式
