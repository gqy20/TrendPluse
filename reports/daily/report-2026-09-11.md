## ⚠️ Breaking Changes

### [cline/cline](https://github.com/cline/cline) `desktop-v0.0.26`

- 🟡 **[Behavior]** Skills 标签页新增启用/禁用切换功能，此前桌面应用没有禁用技能的概念，被禁用的技能将被隐藏且无法访问
- 🟢 **[Behavior]** Customize 视图的 Tools、Skills 和 Rules 标签页统一为一致的列表样式，与 Plugins 模式保持一致，标签页顺序调整为 Tools、Plugins、Skills、Rules、MCP、Hooks
- 🟢 **[Behavior]** 侧边栏的 "New Task" 按钮更名为 "New Session"
- 🟡 **[Behavior]** 不再支持 HEIC、TIFF、SVG、BMP、ICO 等格式的图片附件，在附件选择、粘贴或拖拽时即被拒绝
- 🟡 **[Behavior]** ChatGPT (Codex) 退出登录现在会同时清除遗留的 Codex 凭据，之前退出后运行时仍会从经典扩展的存储凭据中重新导入
- 🟢 **[Behavior]** 提示遥测数据现在仅限 Cline 和 Cline Pass 请求，使用自有提供商密钥的对话不再被追踪
- 🟢 **[Behavior]** 从 composer 的提供商选择器中移除了 "Configured" 勾选标记（0.0.25 版本新增）
